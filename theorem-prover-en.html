Automated Theorem Prover (ATP)

Symbolic Computation and Deductive Artificial Intelligence engine in Propositional Logic. Designed to maximize performance via syntactic manipulations on Binary Abstract Syntax Trees (AST) while delivering transparent step-by-step auditing for every CNF rewrite rule and Robinson's Resolution refutation.

1. Overview

The Automated Theorem Prover (ATP) is a symbolic computation engine that automates formal argument validation in Propositional Logic. Given a set of premises P1, P2, ..., Pn and a conclusion C, the system proves whether the argument forms a valid deduction.

Efficiency with Binary Syntax Trees (AST)

Traditional Truth Tables suffer from exponential combinatorial blowup, requiring 2N evaluations. With just 20 variables, they demand over 1,048,576 rows.

This system employs Binary Abstract Syntax Trees (AST) to replace exhaustive evaluations with direct symbolic transformations in memory, achieving high speed with minimal resource consumption.

Step-by-Step Transparency & Auditing

Unlike "black-box" solvers that only return a boolean value, this prover audits and prints the complete deductive proof trace.

It displays the expression after Proof by Contradiction, every equivalence during Conjunctive Normal Form (CNF) conversion, and each selected resolvent literal until refutation.

2. Architecture

The system operates through a modular 5-stage symbolic transformation pipeline:

1

Parsing & Formal Analysis

Parses raw formula string, identifying atomic propositions, connectives, and operator precedence.

2

Binary Abstract Syntax Tree (AST) Construction

Generates an in-memory binary representation storing operators or literals with parent/child navigation pointers.

3

Proof by Contradiction (Reductio ad Absurdum)

Negates the conclusion to check whether premises plus negated conclusion (P1 ∧ ... ∧ Pn ∧ ¬C) yield a contradiction.

4

Conjunctive Normal Form (CNF) Normalization

Applies iterative symbolic equivalences (eliminating conditionals, De Morgan, distribution) to transform the AST into conjunctions of disjunctive clauses.

5

Prover Engine (Robinson's Resolution Method)

Extracts clauses and executes Robinson's Resolution to derive the empty clause (□), certifying absolute theorem validity.

3. Syntax Tree (AST)

At the core of the engine's speed is the Binary Abstract Syntax Tree data structure:

Bidirectional Nodes

Each node maintains pointers to left, right, and parent. This enables in-place subtree rotations, local substitutions, and negation propagation without costly string re-parsing.

In-Order Inspection & Traversal

Symmetric traversal (left → root → right) prints intermediate expressions at every transformation step for step-by-step visual auditing.

4. CNF Normalization

To enable resolution proof, any propositional formula is converted into Conjunctive Normal Form (CNF) applying the following symbolic equivalences:

Conversion Stage Applied Logical Equivalence Structural Impact
1. Biconditional Elimination A ⇔ B ≡ (A ⇒ B) ∧ (B ⇒ A) Splits equivalences into two implications joined by conjunction.
2. Conditional Elimination A ⇒ B ≡ ¬A ∨ B Transforms implications into disjunctions with negated antecedent.
3. De Morgan's Laws ¬(A ∧ B) ≡ ¬A ∨ ¬B
¬(A ∨ B) ≡ ¬A ∧ ¬B		 Pushes negations down to leaf nodes (atomic variables).
4. Double Negation ¬¬A ≡ A Cancels double negation pairs.
5. Disjunction Distribution A ∨ (B ∧ C) ≡ (A ∨ B) ∧ (A ∨ C) Applies distribution to guarantee final conjunctive clause structure.

5. Robinson Resolution

Once CNF is achieved, the expression becomes a clause set S = {C1, C2, ..., Cm}. The engine executes Robinson's Resolution Method to refute the negated set:

💡

Robinson's Resolution Method

Given two clauses with complementary literals C1 = L ∨ A and C2 = ¬L ∨ B, the system derives the resolvent R = A ∨ B. Iterative resolution aims to derive the empty clause (□), proving the negated set unsatisfiable and certifying the theorem VALID.
